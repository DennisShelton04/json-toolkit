# Changelog

All notable changes to this project are documented here ([Keep a Changelog](https://keepachangelog.com), [SemVer](https://semver.org)).

## [0.1.0] — 2026-09-29

### Added

- Beautify (2/4/tab), minify, recursive key sort
- Syntax validation with line/column, duplicate-key warnings, live editor linting
- Auto-repair of common JSON mistakes
- JSON Schema validation (draft-07, 2019-09, 2020-12)
- Semantic diff (added / removed / changed, JSONPath locations)
- JSONPath query (safe evaluation)
- Conversion: JSON ⇄ YAML, JSON ⇄ CSV
- TypeScript interface generation
- Escape / unescape
- Tree view with copyable paths, document stats, file open / drag & drop, copy, download
- Light/dark theme, local persistence, production CSP, CI/CD, Docker image
